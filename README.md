Sitio web oficial de **GRIP Climbing Club** — Muro de Escalada en Calarcá, Quindío.

🌐 **Sitio en vivo:** https://droko1982.github.io/grip-climbing-club/
📷 **Instagram:** [@murodeescaladagrip](https://www.instagram.com/murodeescaladagrip)
📍 **Ubicación:** [Google Maps](https://maps.app.goo.gl/XomwvZX1Xtsj72qs8)

---

## Sobre el sitio

Sitio web one-page optimizado para SEO local en todo el departamento del Quindío (Armenia, Calarcá, Montenegro, Quimbaya, Circasia, La Tebaida, Salento, Filandia, Pijao, Génova, Buenavista y Córdoba).

### Secciones

- **Inicio** — Hero con identidad de marca y CTA principales
- **Sobre Nosotros** — Filosofía y propuesta de valor
- **Servicios** — Escalada libre, clases, entrenamiento, salidas a roca, eventos
- **Precios** — Pase de día, mensualidad, clases
- **Horarios** — Lun–Vie 3:00 PM–9:00 PM · Sáb 2:00 PM–6:00 PM
- **Ubicación** — Google Maps + listado de municipios atendidos
- **Contacto** — Enlaces a Instagram y Google Maps

### Optimizaciones

- HTML semántico con `<meta>` SEO y geo-tags (`geo.region=CO-QUI`)
- JSON-LD `SportsActivityLocation` con `areaServed` para todo el Quindío
- Open Graph + Twitter Cards
- `sitemap.xml` y `robots.txt`
- Mobile-first responsive
- Animaciones suaves y reveal-on-scroll

## Stack

HTML5 + CSS3 + JavaScript vanilla. Sin frameworks ni dependencias.

## Despliegue

El sitio se publica automáticamente con **GitHub Pages** desde la rama `main`.

Para activar:
1. Settings → Pages
2. Source: `Deploy from a branch`
3. Branch: `main` / `(root)`
